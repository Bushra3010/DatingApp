Bot profiles

Profiles you make and add photos to by hand, for testing, demos and store screenshots. Bots are shown to every member, always labelled “Sample profile” in the app, so nobody takes them for real people. They can’t sign in.

Policy

Bots must always be labelled to users as “Automated profile”. They must never pretend to be real people, solicit money or personal data, or chat with real users as if human. Auto-like, auto-match and auto-reply run only in Demo or Staging against internal test accounts.
